# MetaEdit: бесплатный редактор метаданных для Mac (музыка, фото, видео и любые файлы)

**MetaEdit** — бесплатный редактор метаданных и тегов для macOS с открытым исходным кодом. Откройте любой файл,
посмотрите все его метаданные, измените и сохраните. Теги MP3, FLAC и M4A, обложки альбомов, EXIF, IPTC и XMP
у фотографий, теги видео и теги Finder — в одной простой программе. Можно выбрать сразу много файлов
и изменить их вместе.

Сам файл никогда не перекодируется и не пережимается. Меняются только метаданные: звук, видео и пиксели
остаются точно такими же.

[**Скачать для macOS**](https://github.com/j-tap/meta-edit/releases/latest) · [English](README.md)

## Возможности

- **Одна программа для всех типов файлов.** Музыка, фото, видео, документы и обычные файлы. У неизвестных
  файлов можно менять имя, даты, теги Finder и комментарий Finder.
- **Пакетное редактирование.** Выберите весь альбом и задайте жанр, исполнителя или обложку сразу всем трекам.
  Если значения у файлов разные, поле показывает «Multiple values», а одно из существующих значений можно
  применить ко всем.
- **Подтверждение перед изменением нескольких файлов.** Видно, какие поля и в скольких файлах изменятся.
  Опция «Only where empty» заполняет только пустые поля и не трогает заполненные.
- **Без потерь.** Теги переписываются на месте, аудио, видео и изображение копируются байт в байт.
- **Не удаляет непонятное.** Неизвестные теги, данные камеры, цветовые профили и IPTC остаются в файле.
- **Все теги.** Кроме основных полей, показан и доступен для правки каждый тег файла.
- **Обложки.** Просмотр, замена, удаление и экспорт встроенной обложки.
- **Сохраняет дату изменения** файла при записи, если включено в настройках.
- **Нативная и лёгкая.** Swift и SwiftUI, около 5 МБ, ничего дополнительно ставить не нужно.

## Поддерживаемые форматы

| Тип | Форматы | Что можно менять |
|---|---|---|
| Аудио | MP3, FLAC, OGG Vorbis, Opus, M4A (AAC, ALAC), WAV, AIFF, APE, WavPack, Musepack, WMA, DSF, DFF | название, исполнитель, альбом, исполнитель альбома, год, жанр, номер трека и диска, композитор, комментарий, текст песни, BPM, ISRC, обложка и любой тег (ID3v2, Vorbis, MP4, APE, ASF) |
| Видео | MP4, M4V, MKV, WebM | название, автор, описание, комментарий, жанр, обложка и другие теги |
| Изображения | JPEG, PNG, TIFF, HEIC, AVIF, GIF, JPEG 2000, PSD (WebP и RAW только чтение) | название, автор, описание, ключевые слова, копирайт, рейтинг, заголовок, город, страна, метка и любой XMP-тег; данные камеры EXIF показываются |
| Любой файл | все | имя файла, теги Finder с цветами, комментарий Finder, «Откуда загружено», даты создания и изменения |

В планах: PDF и офисные документы, необязательная интеграция с [ExifTool](https://exiftool.org) для RAW, MOV
и редких форматов, версии для Windows и Linux.

## Установка

1. Скачайте `.dmg` из [последнего релиза](https://github.com/j-tap/meta-edit/releases/latest).
2. Откройте его и перетащите **MetaEdit** в **Программы**.
3. Приложение пока не заверено Apple, поэтому macOS блокирует первый запуск. Откройте его один раз, затем
   зайдите в **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
   Или выполните в Терминале:

   ```
   xattr -dr com.apple.quarantine /Applications/MetaEdit.app
   ```

Нужна macOS 14 Sonoma или новее, Apple Silicon или Intel.

## Как пользоваться

1. Перетащите файлы или папки в окно или нажмите ⌘O. Папки добавляются со всеми вложенными.
2. Выберите один файл или несколько (⇧⌘A выбирает все).
3. Измените поля. У изменённых файлов появляется оранжевая точка.
4. ⌘S сохраняет выбранные файлы, ⇧⌘S сохраняет все изменённые.

## Частые вопросы

**Как изменить теги MP3 на Mac?**
Перетащите MP3 в MetaEdit, поменяйте название, исполнителя, альбом или жанр и нажмите ⌘S. Записываются теги
ID3v2, звук не меняется.

**Как поменять жанр или обложку сразу у всего альбома?**
Добавьте папку альбома, выделите все треки, введите жанр или перетащите картинку на обложку, сохраните
и подтвердите.

**Как изменить метаданные фото (EXIF, IPTC, XMP) на Mac?**
Откройте фото, измените название, описание, ключевые слова, копирайт или место и сохраните. Изображение
не пережимается, качество не теряется.

**Ухудшится ли качество после правки тегов?**
Нет. MetaEdit не перекодирует аудио, видео и изображения. Автотесты сравнивают звук и пиксели до и после
каждой записи.

**Это бесплатно?**
Да. MetaEdit бесплатна, исходный код открыт под лицензией MIT.

## Сборка из исходников

```
git clone https://github.com/j-tap/meta-edit.git
cd meta-edit
brew install cmake
make macos            # собирает apps/macos/dist/MetaEdit.app
make test-macos       # запускает тесты
```

Хватает Xcode Command Line Tools, сам Xcode не нужен. Подробности в [apps/macos/README.md](apps/macos/README.md).
